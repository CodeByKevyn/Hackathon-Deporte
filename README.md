# Tribuna Tricolor ⚽

**Equipo:** Tribuna Tricolor  
**Ubicación:** Sala 12  

---

## 📝 Descripción

Tribuna Tricolor es una página web para explorar camisetas de equipos de fútbol colombianos. Permite consultar un catálogo y agregar productos a un carrito de compras, donde se puede modificar la cantidad y ver el total en tiempo real.

---

## 🛠️ Tecnologías

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **Bootstrap 5**

## 🚀 Funcionalidades

- **Catálogo de Camisetas:** Visualización dinámica de productos del Fútbol Profesional Colombiano.
- **Carrito de Compras:** Función para agregar, sumar, restar y eliminar camisetas.
- **Envío Gratis:** Barra de progreso dinámica que calcula cuánto falta para obtener envío gratuito.
- **Persistencia con LocalStorage:** El carrito guarda tus productos aunque recargues la página.
- **Diseño Responsivo:** Adaptado para dispositivos móviles, tabletas y computadores con Bootstrap.
